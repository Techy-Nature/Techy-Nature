# Heart on our+ sleeve, story on our+ lips, nature in our+ veins

Hi, we+ are **Nest** (Neston Linden Toftwyn), they/them/ask us+: a designer, coder and writer based in Yankton, South Dakota.

We+ like making things that are easy to use and easy to love: clean, accessible interfaces, stories with room to breathe, and tools that handle the fiddly parts for you. We+ learned UI/UX through Google's course on Coursera, took photography classes along the way, and writing has always been our+ strongest craft.

## What we+ make

### Design

**UI and UX design:** interfaces built around real people, with accessibility baked in from the start.

### Code

- **[Duplex](https://github.com/Techy-Nature/duplex-story-format)**: A custom Twine 2 story format. Switch between a scrolling transcript and page-by-page passages, with a dyslexia-friendly font option and sidebars you can stow away.
- **[Plurapack](https://github.com/Techy-Nature/Plurapack)** *(alpha)*: A bot for plural communities on Stoat and Fluxer, with its own web dashboard.
- **[NestSigner](https://github.com/Techy-Nature/NestSigner)**: An Android app for making signing keys and signing APKs, no command line needed.
- **[NestASAR](https://github.com/Techy-Nature/NestASAR)**: An Android app for packing, extracting and browsing Electron .asar files.
- **[NestSync](https://github.com/Techy-Nature/NestSync)**: An Android, Linux and MacOS app for keeping Git repos synced up with the local copies.
